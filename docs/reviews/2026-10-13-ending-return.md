# ゴール後の編集復帰

2026-10-13 / 0.15.0。ゴール後に「停止を押す」または「一定時間待機」で編集へ戻す依頼に対し、推奨した「全粒の動作終了後に3秒」へ発案者が「では3秒で」と回答した。0.14.0で相談中だった開始条件を解消し、旧版の明示停止だけという条件に優先する。

## 動作

後続粒の記録を途中で切らないため、最初の到着からではなく全粒の動作終了から待つ。ゴール到着がある実行の動作が終わると、画面用の時間で3秒待って編集へ戻る。「停止」は待機中でも即時に使える。待機は計算・到着・処理・採点・記録時間に含めない。通常再生と「次動作」による終了に共通して適用する。

手動と自動は同じ停止処理を使い、点・配線・設定・全記録・点数・保存済み回路・成績を保持する。終了した粒の絵は停止と同じく消す。別の実行への切替で古い待機は引き継がず、最初のゴール後に別の粒や循環が動いている間は自動で止めない。ゴール到達がない実行は従来の手動停止を維持する。

負荷・エラーで中断した終了状態は、利用者が停止を選べるよう保持する。記録やメニューを閲覧してもその中断を正常終了に読み替えない。非表示中は自動停止を実行せず、再表示後に待機が経過していれば戻す。待機中に開いた記録やメニューは勝手に閉じない。

間隔の定数は`src/ui/end-wait.js`の`END_WAIT_MS = 3000`。画面更新から終了を検知するため、実際の復帰は3秒を経過した次の画面更新で行う。
