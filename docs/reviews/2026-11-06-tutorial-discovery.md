# 自分でつなぎ、三つの響きをつくるチュートリアル

2026-11-06、0.102.0。発案者の「意図が伝わる」「動きがあり、遊びたくなる」依頼と構成の承認に基づく。追加回答の「一度の実行で複数回鳴る気持ちよさ」「FM音源の鐘の音程」を最後の実操作の見せ場に採用した。

## なぜ変えたか

従来は最初の1本を結んだ直後に削除を要求し、鐘が鳴る楽しさより操作説明が先に来ていた。またQ1の左右は同じ2.5秒なので、道の工夫による変化を体験できなかった。

新しい練習は、最初の鐘→道を変えて時間を比べる→光を分けて三つの鐘を響かせる、の二章で進む。本番42面・288出題や成績の識別子は変えない。

## 変えたこと

- 練習専用回路で、最初の直通4秒と、B経由2.5秒／C経由3.5秒を実際に鳴らして比べる。初回に最速を発見しても、別の道との比較へ進める。遅くなった試行を「速くなった」とは説明しない。満点になるまでの繰り返しを強制しない。
- 削除は最初の鐘の後に、長押しで1本を消す。設定から直接削除する既存操作も使える。途中の分岐に3本を使い切った場合は、余分な1本を消す案内へ切り替える。
- 記録で比較を確認してから「響きをつなぐ」で三音の章へ進む。7パーツ・6本の左右のバランスを保った回路を自分で組み、1回の実行で鐘1が2秒、鐘2が2.5秒、鐘3が3秒に鳴る。既存のFM鐘の音色とC/G/高いC（MIDI72/79/84）を使う。音の生成処理・優先制御・保存済み遅延値を変えない。
- 案内を目的の見出し・今する操作・補足・進度に分ける。起点から終点へ動く指先の輪、線を長押しする輪を実際の盤面へ合わせる。触ったらお手本を止め、離してから再開する。自動配線せず、結線済みの金色と異なる青白い予告にする。
- 案内は盤面外を維持し、短い画面や文字拡大では全文案内へ折り畳む。展開中も「案内を読む」から補足全文を読める。非表示・設定・記録・削除確認ではお手本を止める。控えめ設定では静止した矢印と輪へ切り替える。
- 拡大文字の狭い画面は最初から全文入口へ揃え、到達後の長い文章で途中から案内を畳んで盤面を動かさない。「お手本」「次へ」は同じ高さの行へ置き、短い表示にも完全な読み上げ名を付ける。
- 高さ850px以下のPCでは、練習中だけ副次的な経過時間欄と補足を譲り、主操作を画面内に確保する。重複していた見出しの「チュートリアル」は副題側へ集約した。補足は全文入口から読める。
- スマホの画面全体を縦スクロールさせない条件を、タイトル・各案内・再生・記録・全文案内・クリア・復元後へ追加した。長い読み物の内部表示と、ページ全体のはみ出しは分けて検査する。
- 左右への回転検査で、版表記が横にはみ出し、ブラウザの自動縮小により844×390指定が850×393になる状態も検出した。横置きフッターの28px、拡大文字の70px、短画面の60pxという別々の固定指定を文字サイズに応じる共通領域へ揃えた。版番号・著作権を切り捨てず、実際の表示領域と自動縮小の倍率も照合する。
- 最後の三到達を見せ、既存の結果待機を経てクリア画面を出す。通常の花火とファンファーレを最後の章だけに使い、単発の練習には重ねない。三つの到達時刻、前半の比較時間と点数、条件を満たして早く届けるほど高得点・最速100点という説明を載せる。

## 保持したこと

元の回路・点の設定・実行記録・表示・モードの控えと復元、スキップ、完了履歴、保存失敗時の再試行、自由作成での時間変更練習を保持した。練習は通常の成績・保存回路へ混ぜない。過去の実行・途中停止・早すぎる記録では進めない。

通常42面の構成、秒数、採点、時計、音色、最後の到達、結果待機設定は変更しない。表示・資材の読み込み版を0.102.0へ上げた。

## 小型画面・文字拡大の描画負荷

320×480・文字28pxの実再生で、開始直後または0.5秒で負荷による自動一時停止を記録した。ある再現では1フレーム150.9ms、内訳は計算0.2ms・音0.3ms・表示150.4msだった。別の同条件の計測では、秒数表示の位置決めが68回、専有時間の合計4366.6ms、最大151.7msで、再生中にも90ms台の呼び出しを複数確認した。同一フレームでの詳細計測ではないため、ホストの負荷変動まで含めた最初の停止との厳密な原因一致は断定しない。

この二つの練習回路は循環せず、各プリズムへ光が1個しか届かない。その条件に限って処理中表示の場所を初めから確保し、秒数カードを処理開始/終了ごとに探し直さず、位置を保つようにした。開始演出ですでに描いた盤面の、開始時の重複再作成もこの練習だけで省く。案内の本文3行・補足2行の高さを確保し、実行中の文章切替で盤面を動かしにくくした。

通常面・自由練習・待ち行列・故障・開閉の動的なラベル配置処理と、計算/表示の負荷停止の基準は変えない。停止を自動再開して合格にせず、同じ画面と文字サイズで再検査する。

修正後の同条件の計測は停止なしで完走した。各再生中の位置決め呼び出しは0回、三音の再生中182フレームでカード位置の差は最大0pxだった。編集/停止時を含む位置決めは68→57回、合計4366.6→2889.8ms。初回4秒・比較2.5秒と、三つの鐘の2秒/2.5秒/3秒と音程を保持した。開始時は前回の到達演出だけを消し、短い待機設定でも前の星座を引き継がない。
