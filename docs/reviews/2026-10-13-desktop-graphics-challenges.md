# PC表示・採用画像・課題構成の見直し（0.20.0）

2026-10-13。公開準備中。GitHub反映・公開確認は下段へ追記する。

## 発案者の指示と訂正

PCの通常表示はヘッダが上、操作が下、Sが下・Gが上。スマホの左右回転は端末基準の配置を保持する。幅の広いPC窓を端末の横置きと同じ扱いにしていたことを修正した。

採用画像はS1/P5/G3/R1/O2。線画で似せる方式から、採用候補を参照した透過PNGと背景PNGを表示する方式へ変更。[生成指示と原本](../../画面案/グラフィック候補_v0.1/README.md)を保持する。実装用の透過化・横長背景は生成による再構成で、比較画像と全画素が同一という保証ではない。PCとスマホ相当の実アプリ画像で確認する。

発案者からQ6の混雑、課題内容、最初の例示、S→B・B→G・B→Cの試行候補、ダイクストラの検証として最短を探す面白さを重視するよう指示された。道を減らして学習順に単純化する捉え方を訂正し、正解に使わない候補も試行できる構成へ変更した。案.xlsxは以前の「変更へ混ぜない」という指示の扱いから、今回明示された検討材料へ変更。原本は編集しない。原本内の図と道・中継処理を足す2.5/4.5/6.5秒の例を読み直した。図の全数値を全課題へ機械的に転記したものではない。

配線の秒数カードの横向き矢印は意味が紛らわしいとの指摘を受け削除した。カードは秒数だけ。接続の向き・両方向・保存値・計算は保持し、対象の設定や説明では始点と終点を確認できる。

## 課題構成

6課題は初期セットであり、総課題数・プリズム数の上限ではない。今後も追加し、点と接続候補を増やして試行錯誤の幅を広げる方針。追加の具体的な件数・内容は未確定で、0.20.0に追加課題を実装したとは扱わない。自由モードのプリズム追加は既存通り使える。スマホで読めない図そのものを難しさにしない。

|課題|候補数 / 結線上限|プリズム|試せること|
|---|---|---|---|
|Q1|4 / 2|2|導入。二つの最良経路で操作と2.5秒の到着を試す|
|Q2|8 / 3|3|直結寄りのS→C→Gは3秒、S→A→C→GとS→B→C→Gは2.5秒。少ない道が必ず速いわけではない|
|Q3|8 / 3|3|2本と3本で2.5秒になる候補がある。時間を優先し、同時間の時に通った道の本数で比較する|
|Q4|8 / 6|3|合流や迂回を選び、どの道一本が使えなくても届くかを調べる。基準2.5秒|
|Q5|8 / 6|3|Q4と同じ図を中継点故障で試す。共通中継点が弱点になる構成と、避ける構成を比較する。基準2.5秒|
|Q6|8 / 6|3|並行した直通道を中継経路へ分ける。S→B・B→G・A→B・B→Cを含み、分岐・合流で到着回数と間隔が変わる。初回最善1秒、2秒間隔、総3回|

Q4でSA/AC/SC/CG/CB/BGを結ぶと、全単一道故障に耐え、最も遅いケースは3.5秒。同構成のCが止まるとQ5は不達になる。Q6でSA/AG/SB/BG/BC/CGを結ぶと1/3/6.5秒となり未達成。三つの中継経路では1/3/5秒となり100点。A→Bを使う別の最良構成も成立する。全許可組合せを列挙し、各課題で複数の最高評価構成を持つことと基準時間を検証する。

Q2～Q6の課題内容版を2へ更新。旧版成績は削除せず新版成績と別に保持する。採点式、初回出発の処理時間を加えない条件、保存枠、保存した回路は変更しない。未達成の試行も禁止しない。

## 画面と案内

点の間隔を広げ、秒数カードはまず同じ道の空き区間に置き、点・名前・処理状態・他カードを避ける。必要な時だけ離して対応線を出す。PNGに選択と結線候補の印を重ねる。背景は入力の対象にしない。保存座標の表示・逆変換とスマホの方向保持を維持する。

案内中に課題選択を開くと、元の回路・記録へ戻る操作を提示する。「案内を続ける」は保持。元の実行が一時停止中なら、明示停止してから課題を選ぶ。未保存回路の保存確認、案内履歴保存失敗時の再試行、全記録の保持を維持する。終了した案内を誤って再開したり、課題の切替をエラーで行き止まりにしない。
