# 受入条件と現在の証拠

2026-10-13。要件定義書v1.9のAC-01～26、F-001～026、NF-001～008を維持する。公開版0.9.0はコミット938b953ba7bcf35ff6836578fd326da5e4bd3e8aと公開37項目を照合した。これは完了宣言ではなく、確認した部分と未確認部分の対応表である。要件から実装タスクへの対応の正典は[tasks.md](tasks.md)。

## 証拠の読み方

自動テストは計算・状態・保存の合成条件の証拠。ブラウザ試験は記載されたPCブラウザ・画面寸法・操作の証拠。実際の指操作、ソフトウェアキーボード、OSの文字拡大、端末からの音、PWAのOS終了後の保持を代用しない。PC上のWebKitは実機Safariではない。

受入条件の途中に合格した部分があっても、行全体を完了へ変更しない。証拠が古い版の場合はその版を明記する。試験器に付けた要件タグだけで受入の完了を判断しない。下表の「残る確認」は実装から外す項目でも、利用者へ一つずつ選択を求める質問数でもない。

## 非機能8項目

| 条件 | 現在の証拠 | 残る確認 |
|---|---|---|
| NF-001 正確性 | 正確な小数・独立した経路列挙・手計算の記録・追加到達の成立条件、全6課題の基準値 | 端末の描画/音の遅延を計算時刻と分けて記録 |
| NF-002 性能 | 計算/要素更新/音呼出/記録の処理時間、合成遅延による停止と状態保持 | 実機の実描画・実音出力を含む負荷。12ms区切り・50msが3回・120ms単発は暫定値 |
| NF-003 保護 | 一度の保存書込、元データを先に消さない、未知版/破損拒否、合成保存失敗と再試行 | 実機の実容量・ファイルアクセス制約。試験用データと利用者データを区別 |
| NF-004 復帰 | その場の一時停止と再開、手動保存のみ保持、通信なし再読込 | OS終了・再起動・保存領域の整理。未保存編集/途中状態の永続復元は追加しない |
| NF-005 操作 | PCで一画面・回転・文字拡大・ドラッグ・設定・案内・消音表示を確認 | 全対象実機の指・キーボード・文字拡大と理解。PCのWebKitをSafari実機にしない |
| NF-006 運用 | GitHub Pages、版付き資材、明示更新と復旧、CIの検査/版確認/配信、画像とフォントの出所 | 実機更新・運用担当と運用上の希望が必要な場合に確認 |
| NF-007 移植 | 形式版1・用途別JSON・読込検査、PCの回路往復と同記録 | 異なる実端末で渡して同条件の結果を比較 |
