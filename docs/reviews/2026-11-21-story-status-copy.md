# 物語の不要な再生説明を削除（0.106.0）

通常の再生状態を説明する文字が物語の本文に併記されていた。発案者の「開発者向けでは」「不要では」という指摘を受け、読む・進むために必要のない表示を削除した。

## 変更

- 「余韻が静かになりました」、声や鐘の再生開始・聴き方、無音場面の説明、切替時の重複案内を削除。余韻終了の説明だけに使っていたタイマーも削除した。
- 曲の未収録・手動進行に関する重複した補足を削除。エンディング曲の予約場面と「楽曲は準備中です。このまま進められます。」は保持した。
- 空の状態欄を非表示にし、章の案内もない場合は補足欄全体を配置から外す。
- 読み込み中・失敗と再試行、停止・一覧・画面非表示後の再開案内は保持した。
- 物語27枚の文章と絵・琴の固定・音色と音程・鳴動時間・設定共有・最大300msの切替、42面288出題・時計・採点・記録・保存は変更しない。表示/読込版は0.106.0。
