# チュートリアルで記録を開いたときの空白

2026-11-07、0.103.0。Pixel 9aのChrome、0.102.0で「記録」を開くと、上側に大きな空白ができ、盤面が縦に押し縮められたとの報告に対応する。

## 原因と変更

案内を重ねて読む画面では、背後の盤面を動かさないため、案内カードを見えなくして高さを保持していた。記録欄にも同じ処理を使い、見えない案内の約200pxが残っていた。音や実行記録の中身には依存せず、実行前でも「チュートリアル→記録」だけで再現する。

`TutorialGuide.update`に記録表示中を伝え、この場合だけ案内カードを配置から外す。空いた場所は盤面と記録欄へ返す。設定や全文案内のように説明を重ねる画面は、高さを予約する従来の動きを保持する。記録を閉じたら、既存の再描画で案内を戻す。

回路・実行・時計・音・採点・練習の進行を変えない。本番42面288出題を保持する。画面表示・資材の読込版を0.103.0へ上げる。

## 再現の検査

[検査器](../../設計検証/check_tutorial_records.cjs)で、星→A→鐘を実行してから記録を開く実操作と、実行を省いた最小操作を検査した。どちらも修正前は「盤面の前に空白行を残さない」の条件で不合格、修正後は合格した。410×844の画面相当の[修正前](../../設計検証/チュートリアル記録-20261107/before-real/records-open.png)・[修正後](../../設計検証/チュートリアル記録-20261107/after-real/records-open.png)を保持する。

同条件の実行後の測定では、ヘッダと盤面の間が210.406px→通常の間隔5px、盤面の高さが244.625px→371.984pxとなった。記録欄にも空間が戻り、複数行を表示できる。ページ全体の高さは表示領域と同じ844pxを保った。

前回の二章検査は、記録行の表示、ページ全体のはみ出しなし、お手本の停止を確認したが、記録表示中の空白・案内の占有高・盤面の有効な高さを検査していなかった。従来の62項目合格を、今回の表示崩れがない証拠とはしない。記録表示中の配置を独立した状態として検査へ加える。
