# 音程と未結線の開始条件

2026-10-13 / 0.17.0。発案者の「鐘の音、中継点の音ともに音程を上げる」「鐘は5度上」「全く結線していない状態でもスタートできるため改善」に対応する。完全未結線を有効な開始としていた旧条件を置き換える。

鐘は以前の174.6Hzを7半音上（完全5度）へ移し、約261.61Hzにする。1オクターブ上も同時に混ぜ、他の倍音と余韻・音量・計算と記録の時間を維持する。設定はsrc/ui/audio.jsのBELL_SOUND。中継音の上げ幅は実装選択として同じ5度上を採用し、440→587.33Hzから659.26→880Hzへ変更する。約0.2秒の音と到着時1回、移動中の無音、鐘との分離・消音・停止を維持する。聴感による採用判断は未確認。

Session.startは配線0本の時に状態を書き換える前に拒否する。画面も共通の理由で「流す」を無効にし、理由を表示する。課題・自由・案内、クリア・最後の道の削除後も対象。1本以上の途中結線や不達回路は開始でき、既存の採点・故障ケースの試行を維持する。使用不能な道が含まれていても回路に道が存在すれば試せる。到達可能な経路の存在を開始条件へ追加しない。

クリア後に開始を要求しても、直前の停止後の実行・全記録・点数・保存回路と未保存編集を保持する。配線の復元や追加後は再び開始できる。以前の完全未結線による未達成テストは、1本だけ結線した不達回路へ変え、未達成0点・成績候補なしの確認を維持する。計算の下位処理へ開始制限を追加せず、経路の検証範囲を減らさない。
