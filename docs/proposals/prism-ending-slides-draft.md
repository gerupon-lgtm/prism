## ねらいと前提

つないだ光の道を曲とともに振り返り、星の精霊からの感謝と鐘の余韻でPRISMの旅を閉じる。その後の時代へ進む予告は、曲の自然終了後に分ける。

【確定】v0.1.10の旋律・和音・構成を使う。3音を変えたv0.1.11のサンプルは採用せず、ファイルは残す。仕上げ版v0.1.12はパーカッションの音色と音符を保ち、音量だけ2dB上げる。約3分6.67秒、最後の鐘は3:00から約6.18秒を保持する。

【確定】ドヴォルザークの旋律を引用していることをスライドへ明記する。最終クレジットはROOTの方針に合わせ、作品固有の絵と物語はPRISMに合わせる。

## 現状を確認したこと

- PRISM本体0.106.0のE2は、星渡りの回廊に3つの鐘と光を置き、水殿・天文台・鏡の背景を薄く重ねた仮の全景。曲の予約表示があり、3分間の複数背景はまだない。
- 現在の結末は、E1「最後の鐘」→E2「つながった夜空・曲の場面」→E3「精霊のお礼」→E4「静かな夜空」→E5/E6「長い時の後の鍛冶場と琴」。すべて通常の手動スライド。
- ROOTの現行公開版0.9.47（88bc6ae0d4ad20b81af21a13ca212e584256fbb2）と同じコミットのソースを確認。曲中は12場面が時刻に沿って替わり、自然終了後に静止した作品クレジットへ移る。
- ROOTの最後は、二人の精霊と三角形の琴の絵に **SIKUMI LAB / SIKUMI NOTES 04 / ROOT NOTES** を重ねる。感謝の文とタイトルへ戻る入口を添える。長いスタッフ一覧を流す形式ではない。

ROOTはPCの新しいブラウザ環境で最後の扉→結末→曲の入口を操作し、再会の場面と曲末を頭出しして確認した。クレジットの縦・横と、PRISMのE2を撮影。曲全編を実時間で通して聴いた検査・実機確認とは区別する。

## 承認された構成と独立試作

**E1の達成 → 曲付きの背景13場面 → E5/E6の後日譚 → 最後の作品クレジット。**

独立試作ではE3の感謝とE4の余韻を曲の終盤へ取り込み、曲の後に同じ文章を再掲しない。E2〜E4を曲付き区間へ再構成し、13場面は音源の再生位置に合わせる。曲の前後の文章は手動で進む。一弦の琴は、曲と最後の鐘が終わった後のE5/E6へ置き、琴・ハンマーの位置と大きさを2枚で固定する。

曲中は説明を増やさず、絵を主役にする。ROOTの武具紹介や二人の和解はPRISMへ移さない。ROOTから引用した主旋律も星の精霊のパートなので、その区間は星の精霊を主役にする。弦の精霊を曲中の新しい登場人物として追加しない。

### 音楽の引用表記【依頼を反映した文案】

> ドヴォルザーク作曲
> 交響曲第9番「新世界より」第2楽章より

終盤に約13秒確保し、明るい文字で静かに読む1枚にする。物語の語り・精霊の台詞とは区別する。「影響を受けた」「オマージュ」だけの表記には置き換えない。参考譜面の画像や伴奏は表示しない。

### 最後の作品クレジット【提案】

ROOTと同じ順序の **SIKUMI LAB → SIKUMI NOTES 01 → PRISM NOTES** と、プレイヤーへの感謝を置く。絵は深い青の夜空・白い石・淡い金の光を背景に、鐘と星の精霊。採用済みの精霊は左向きなので、鐘を左・精霊を右に置き、同じ方向を向いてしまわない構図にする。上部に文字のための余白を確保し、文字を絵へ焼き付けない。

後日譚E5/E6の後にこのカードを静止表示し、任意の時間読めるようにする。「タイトルへ」と曲の再鑑賞の入口を候補にする。PRISMで二人の和解が済んだような絵にはしない。

## 素材・動き・操作の見通し

既存の `ruins / observatory / starwalk / moonwater / starecho / starreturn / moonmirror / stargate` と鐘・光源・プリズム・鏡・星の精霊で大部分を構成できる。新規絵の候補は **旅を一望する全景と、最後のクレジット用の絵の2点**。試作では既存素材の組合せでも確認できる。

場面の切替は穏やかなフェードを基本にし、人物・鐘を常に上下へ動かさない。曲へ別の効果音や精霊の声を重ねない。縦は絵と文を上下、横は左右、低い横でも引用表記を小さく押し込まない。本体の音・出力・控えめな演出設定を共有する。停止・再開・頭出しで絵と曲がずれないこと、非表示と離脱の中断、自然な鐘の終了も実装時の確認範囲に入れる。
