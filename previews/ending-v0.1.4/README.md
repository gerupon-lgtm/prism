# PRISM NOTES エンディング確認用 v0.1.4

2026-11-21。曲は確認済みのv0.1.17。パーカッションはv0.1.15から+4dB、全長約3分7秒。スライドの全体構成へのOKを受け、各場面の短い本文とROOT NOTESへの予告を追加した確認用の版。

## 開く

このフォルダにはHTML・スクリプト・画像・フォント・曲がそろっている。リポジトリを取得し、次を実行する。Node.jsの標準機能だけを使用し、追加パッケージは不要。

```powershell
node previews/ending-v0.1.4/serve-preview.cjs
```

表示されたURLをブラウザで開き、「曲を聴く」を押す。`?scene=S03`は「応えた道」、`?scene=E6`はROOT NOTESの予告を直接開く。直接開いた場面では自動再生しない。

ローカルの制作元は `design-preview/ending-slides-2026-11-21/v0.1.4/`。配布用は `previews/ending-v0.1.4/`。どちらも同じ内容で、他フォルダの音源・画像を読み込まない。端末固有の保存パスは不要。
