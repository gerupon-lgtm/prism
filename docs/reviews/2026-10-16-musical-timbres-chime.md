# 楽器音色のジングルと打音を加えたチャイム

2026-10-16 / 0.38.0。実装済み、検証中。

## 今回の指定

発案者は「ジングルなどは、別の音楽的な音色から選んで使う」と指定。続けて、鐘は既存の「チャイム」がイメージに近いと選択し、アタックを強めたいと依頼した。別音色を重ねてアタックを作る方法も認めた。従来の「鐘の採用品は未選択」は今回の指定で解消した。

鐘には調整済み440Hzの2オペレーターFMチャイムを採用し、880Hzの短いエレピを0.06秒だけ薄く重ねた。余韻全体の音量を上げる方法にはせず、本体の比・変調・減衰を基準として残す。末尾は静かに減衰させ、全体は2.62秒以内で終了する。

## 楽器音色の割り当て

サエズリズムの `probe/saezuri/light-voice.js`（`2026-10-03-timbres-v2`）から、必要な3音色と発音・停止の考え方を本プロジェクトへ取り込んだ。原本は編集していない。

| 用途 | 音色 |
|---|---|
| 通常クリアの4音 | エレピ `piano` |
| 100点の8音＋3和音 | 明るいFMエレピ `fm-piano` |
| 未達成の下降2音 | フィルター付き三角波の柔らかい音 `soft` |
| 結線とプリズム到着 | 短いエレピ |
| 操作音 | 短い柔らかい音 |

音量・音色の減衰は元設定を基準とし、離鍵後の余韻を各効果音の既存の発音長へ収める。音楽的な音色を選ぶ指示は、楽器設定の採用方針として扱い、実機での音色の好みまで合格したとは扱わない。

鐘の基準周波数440Hzと、既存ジングルの基準約523.22Hzを分離した。鐘の選択によってジングル全体の音程を変えない。通常・満点・未達成のメロディー、各音の開始時刻と長さ、未達成音の最後の鐘から1.5秒以上の待機、1回だけの再生は保持する。

`src/ui/voices.js` が発音・減衰・停止と解放を担当し、`src/ui/audio.js` が音の種類・選ぶ音色・音量と予約を担当する。発音ごとのまとまりで本体と変調音、鐘と打音を止め、音が終わったら管理対象と接続を解放する。消音・停止・一時停止・メニュー・記録・非表示での取消、再表示時の重複防止を保持する。ゲームの時計・到達記録・採点・保存には音の長さを加えない。

表示版と資材参照を0.38.0へ更新し、新しい発音部品も版付き配信・通信なし準備へ含める。共通音量70%、3秒後の編集復帰、既存の世界観・到達演出・課題・配線操作を保持する。

- `npm.cmd test` は17ファイルを最大5ファイルずつ・並列度1で実行し142件合格。到達時刻・採点・保存・更新保護と全48出題の全配線を含む。
