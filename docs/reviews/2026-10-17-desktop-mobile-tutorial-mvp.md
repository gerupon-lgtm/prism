# PC画面・スマホの課題・チュートリアルとMVP公開

UI対象版：0.46.0。最終公開版：0.47.0。

## 採用した表示

- 発案者が確認したPC案に合わせ、広い盤面の右へ課題名・条件・本数・結果・実行ボタンをまとめた。ロゴ・文字・ボタンと盤面のパーツを拡大し、背景は盤面全体へ表示する。
- PC専用配置は、マウス操作の幅1100px・高さ700px以上で有効。小さな窓・文字拡大・スマホは従来の枠組みへ戻す。同じ操作部品を移動して使い、実行・記録・選択の状態を複製しない。
- スマホのプレイ画面は課題名、クリア条件、配線の上限／使用／残りを読み取りやすく分けた。一覧も課題名と最高点を別の行へ置き、収まる件数でページを分ける。発案者は今回の画像で問題ないと回答。一覧の改善も保持する。
- チュートリアルは盤面内の案内カードと対象の強調を併用する。接続先と鐘に重ならない位置を探し、狭い盤面ではカード幅も調整する。回転しても文章は正立。収まらない短い画面は既存の全文案内を使う。進行・元回路への復帰・成績への非記録は既存処理のまま。
- タイトルの常設「更新確認」を外し、準備済みの更新があるときだけ控え目な「更新」を表示する。手動確認は「遊び方と概要」内の「オフラインと更新」から開く。起動時の自動確認と、未保存データ・別タブを保護する適用処理は保持する。

計算、採点、出題、保存座標、全実行記録、鐘と効果音、開始演出と編集復帰の時刻は変更しない。スマホの端末基準の配置保持も維持する。

## 確認済み

- 計算・保存等の自動テスト：17ファイル145件。構文検査と版付き配信資材48件の生成。
- `check_desktop_layout.cjs`：Windows Chrome／Edge、PC Chromium／WebKitで各7項目。1600×1000・1366×900・1366×768、実際の結線・2.5秒100点・記録・窓の縮小復帰・自由作成。
- `check_tutorial_mobile.cjs`：同じ4ブラウザで各19項目。PCと390×844・412×800・320×640のスマホ相当画面、案内の3段階、対象を隠さない位置、スクロールなし、完了後の元回路と成績保持、課題条件と全12課題の一覧。
- `check_pwa.cjs`：PC Chromium／WebKitで68項目、Windows Chrome／Edgeで各34項目。更新なしの非表示と手動確認、新版の準備と適用、通信なしの再起動、保存・別タブの保護。
- 途中の点検では、検証器の保存形式の読み違い、小画面で案内が接続先を覆う問題、WebKitで16pxが微小に丸められる判定差があった。保存形式を正しく参照し、案内の幅と対象優先の配置を修正し、文字計測には0.1pxの許容を設けた。各ブラウザの最終report.jsonは合格。実行ログに途中の不合格も残す。
- タイトル導線の継続検証ではQ9のクリアが不成立になった。旧固定版の配線を全出題で流用していたため、現在の出題IDに対応する検査済み配線を使うよう検証器を修正した。既存の迂回ドラッグ補助と、要求した配線そのものの一致確認も使い、描画の変化や途中のパーツへの接続を見落とさない。
- 通常操作の点検で、1280×800のPCで記録を開くと盤面側の操作ボタンが縮んで文字が欠けた。記録併記中は盤面操作を段分けし、編集ボタンを必要に応じて折り返すよう修正した。あわせて、自動で編集へ戻った後に無効な停止を押していた旧検証を、停止済みの状態を確認する形へ更新した。
- 通常操作の再確認で既存の`アプリ/report.json`への書込がWindowsのUNKNOWNエラーになった。原因は未特定。過去の結果を消さず、`--release-output`で今回の結果と画像を版別の`アプリ/0.46.0/`へ保存する。検証途中の元のエラーも先に出力し、保存エラーで隠れないようにした。

タイトル導線52項目、回転と縦復帰74項目、通常操作70項目も合格した。記録併記中のボタン修正後は通常操作を両エンジン、大画面操作をWindows Chrome／Edgeで再確認した。最終的な結果は`設計検証/0.46.0実行ログ/final-reports.json`、画像と詳細は`設計検証/PC画面の見直し/`、`設計検証/案内と課題の読みやすさ/`、`設計検証/アプリ/0.46.0/`などに保存する。

## 公開先とデータ

Cloudflare Pagesの`prism-notes`へGitHubのmainを連携し、`prism.sikumilab.com`の専用CNAMEを作成した。Node 24で構文検査・自動テスト・ビルドを行い、distだけを配信する。HTML・版情報・Workerは再確認し、版付き資材のみ長期保存する設定を出力する。表示版・資材版は0.46.0。

GitHub Pagesの既存URLは残す。保存はURLごとに独立しているため、新URLへ成績や保存枠が自動移動する機能はない。旧URLのデータは削除しない。自由回路は従来のファイル書出し／読込みを利用できる。
