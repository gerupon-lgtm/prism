# チュートリアル改訂案：自分の光で、最初の一音を

2026-11-06。発案者の「意図が伝わる」「動きがあり、遊びたくなる」依頼を受け、現行0.101.0を点検した。同日、構成の実装承認を受領。さらに「1回の実行で複数回の鐘が鳴る気持ちよさ」「FM音源の音程が魅力」を重視する追加回答を受け、締めを実際に3つの鐘を鳴らす体験へ変更する。細部の回路と演出は実装担当の判断。

## 伝える体験

道を考える → 自分でつなぐ → 光が走り鐘が鳴る → 道を変えると結果も変わる。この因果関係を、説明を読ませるだけでなく短い実操作で伝える。長い待ち時間や自動操作で見せ場を水増ししない。

現行は最初の線を引く直後に削除を要求し、鐘を鳴らす前に操作の説明が続く。また練習用Q1は左右とも2.5秒で、工夫による時間の変化を体験できない。まず音と到達の喜びを置き、その後に試行錯誤を教える構成へ変える。

## 課題モードの流れ

1. **光の道をつくろう。**「星の光を、あなたの道で鐘へ。まず星からプリズムAへつなごう。」続いてAから鐘を案内する。未結線の区間だけ、起点から終点への動くお手本を表示する。触っている間はお手本を止める。
2. **最初の一音。**「道ができました。『鐘を鳴らす』で光を送り出そう。」実行中は「あなたがつないだ道を、光が進んでいます。」へ切り替える。鐘への実到達で既存の鐘の音と星座演出を出す。盤面をカードで覆わない。
3. **もっと早く届けるには？** 最初の到達4秒を案内欄に示す。「道の長さだけでは速さは決まりません。線の秒数と、プリズムの待ち時間を見てみよう。」A→鐘の線を長押しして1本消す。選択を誤っても最初からやり直させず、足りない操作に応じて案内を更新する。
4. **別の道を試そう。** Aから左右のプリズムを経由する候補を残す。秒数を比べ、早い道を自分で選んで鐘までつなぐ。必要なら「お手本を見る」で早い経路を示す。自動で配線はしない。
5. **工夫が響きに変わる。** もう一度実行。前回と今回の実際の到達時間を並べ、短くなった分を表示する。最速2.5秒なら100点。違う道で3.5秒になっても失敗扱いせず、「前より早くなった。さらに短い道も探せます」と認める。「記録」でどこに時間がかかったか確かめる。最速の試行を強制して進行を止めない。
6. **三つの響きを、自分の回路で。** 比較の記録を閉じてから「響きをつなぐ」で短い分岐練習へ進む。7パーツ・6本の見通しのよい左右対称回路を順に案内し、自分で結線する。1回の実行で3つの鐘が2秒・2.5秒・3秒に鳴る。既存の鐘の音色と採用済みC/G/高いCの音程を使う。0.5秒間隔で余韻を重ね、最後の到達・既存の結果待機を経て終了画面を出す。終了には速さ比較の実時間・点数と分岐の達成を併記し、「条件を満たしたうえで、早く届けるほど高得点。最速なら100点」を伝える。元の画面へ戻る既存操作を維持する。

## 練習専用回路の提案

通常42面・288出題の内容、ID、成績を変えない。課題チュートリアルだけに固定回路を用意する。練習は通常の成績へ保存しない。

- 星S、中央下のA、左右対称のB/C、上の鐘。実際の星・プリズム・鐘の画像と背景を使う。
- 星→Aは0.5秒、A→鐘は3秒。A/B/Cの待ち時間は各0.5秒。星は既存どおり初回の待ちを到達時間へ加算しない。
- A→BとB→鐘は各0.5秒、A→Cは0.5秒、C→鐘は1.5秒。初回4秒、B経由2.5秒、C経由3.5秒。見た目が短い直通より、中継経路が早い気づきを作る。
- 上限3本。最初の2本からA→鐘だけを消し、星→Aを残して別の道へつなぎ直せる。候補は直線6本に絞り、秒数の重なりを実表示で確認する。
- 単に再生した、記録を開いたという操作では進めない。現在の練習段階に対応した実到達と編集を進行条件にする。初回結果、比較結果は別に保持し、停止・不達・過去の結果を成功へ流用しない。

## 動きと画面

- 既存の夜空・金色・青白い光の世界観、ロゴ、精霊を継承する。新しい絵柄やキャラクターは足さない。
- スマホは盤面外の案内欄、PCは既存の右側欄。文章は「目的の短い見出し」「今する1操作」「必要な補足」に分ける。進み具合を小さな段階表示で示す。
- お手本は起点から終点への軌跡と指先の輪。実際の光・仮配線と混同しない形にする。手を離す所で輪が消え、指示の意味を見せる。自動でつながったと誤解させない。
- 結線ができた時、案内が次へ移る時は一度だけ控えめに反応する。再描画のたびに点滅させない。実行中に指示や枠を不要に動かさない。
- 通常の到達音・鐘・演出をそのまま使い、お手本だけで音は出さない。音なしでも操作と到達を理解できる。
- 「控えめな演出」ではお手本を静止した方向表示へ置換。アプリの端末設定に従う選択も維持する。
- 320px幅、短い横画面、文字拡大は既存の全文案内入口を維持。全文へ目的・操作・補足をすべて含める。説明を大きくするために盤面のパーツを隠さない。
- メニュー・記録・設定・タイトル・非表示・終了ではお手本を止め、古い予約を次の段階や通常プレイへ残さない。回転・拡大でも表示座標に追従する。

## 自由作成の案内

自由作成には既存の「2経路を比べる → 線を消す → Aの時間を1.5秒へ変更 → 再実行して3秒を確認」を残す。初回から実行可能な見本なので、この流れは報酬が先にある。目的の見出し、動く操作のお手本、実行中の案内、終了の図解を同じ方針で適用する。

## 保持と点検

練習前の配線・点の設定・記録・表示位置・保存状態・モードへ戻る。スキップ、再閲覧、保存失敗時の再試行を維持する。時計、採点の式、音色、通常面の結果待機を変えない。表示版と読み込み版は実装時に上げる。

単体では正常/別経路/操作間違い/クリア/途中停止/クリア前の記録/スキップ/保存失敗/再開始を点検する。実ブラウザではスマホ相当縦・左右横・PC・小型・文字拡大・通常/控えめ演出で最後まで操作し、盤面と案内の非重複、全文、誤操作の回復、前後の実時間、元状態の復元、音の呼び出しと不要な予約の解消を確かめる。

「楽しい」「説明の意図がきちんと伝わる」は機械検査の成功だけでは断定しない。動く実画面を確認材料にし、スマホ実機での指操作・聴感とは区別して報告する。
