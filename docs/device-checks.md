2. 課題1で星からプリズムA、プリズムAから鐘へドラッグしてつなぐ。ヘッダの「音なし」をタップして「音あり」にし、下部中央の「鐘を鳴らす」を押す。初回到着2.5秒・100.00点の表示、到着時の鐘の音、結線候補が分かることを確認する。消音で音が止まることも確認する。到着後に音を有効にした場合は停止して再実行する。音の余韻は記録の到着時刻へ加算しない。
3. 縦→左右の横→縦への復帰を一連で確認し、縦へ戻したときに全体が縮まないことを確認する。違いが残る場合は版番号をタップして「表示情報」を開く。最初のページが最新の画面情報で、次のページ以降に回転直前の情報が続く。端末名・問題が出た向きと合わせて記録する。情報は外部に自動送信しない。縦置きは星が下・鐘が上であることを確認する。左へ90度倒すと星は右・鐘は左、右へ倒すと星は左・鐘は右となる。盤面と操作欄は端末に対して元の側を保ち、文字・ボタンの中身だけが読める方向へ回ることを確認する。点と道の配置を保ち、文字が読みやすい向きになること、ページをスクロールせず操作できること、回転前の実行・記録が残ることを確認する。盤面を長押しして不要なメニューが出ないことも確認する。
4. 自由へ移る。自由の案内が出たら完了またはスキップし、練習から元の回路へ戻ってから設定・保存を確認する。点・道をダブルタップして設定を開く。時間欄が全選択されること、画面キーボードが出ても入力・確定・取消ができることを確認する。OSやブラウザの文字を大きくした場合も、設定・保存・記録の全文をページ切替で読め、文書スクロールが起きないことを確認する。
5. 「実機確認」のような区別できる名前で手動保存し、回路ファイルを書き出す。保存先の既存枠を勝手に置換・削除しない。10枠とも使用中なら新規保存を中止し、ファイル出力まで確認する。別端末への受渡しと再実行は、ファイルを用意した後に行う。
6. 「オフラインと更新」で準備完了を確認し、端末のホーム画面へ追加する。機内モードなどでWi-Fi・携帯通信を切り、アプリを終了して起動する。課題・自由・保存読込が使えること、回路・成績・案内履歴が保たれることを確認する。単に開いたまま接続を切る確認とは分ける。

## 記録のしかた

各環境ごとに、端末／OS／ブラウザ版、確認した公開版、各手順の合格・不合格・未確認、問題が出た操作を記録する。聞こえた音は実発音の観測、負荷は実際に使った回路と遅れを記録する。PCの合成遅延や音のAPI呼出しを実機結果として転記しない。実行結果や回路ファイルに含まれる利用者の記録を無断で公開しない。

この一連の後も、全故障ケース・循環と待ち列・記録の親子・保存失敗時の退避・明示更新と復旧・OS終了後の保持・実負荷・異なる端末への受渡しなどはAC別に照合する。手順の回路・粒数・時間は試験例であり、製品の上限ではない。
