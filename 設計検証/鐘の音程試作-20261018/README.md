# 鐘の音程試作 v0.1.0

2026-10-18。発案者の依頼により、採用済みの鐘からWAVを生成。アプリ本体へ未採用。

| ID | 内容 | 到達の間隔 |
|---|---|---|
| D1 | ミ → ド。2つの鐘へ0.5秒差で到達するイメージ。 | 0秒 / 0.5秒 |
| H1 | ド → ミ → ソを0.12秒ずつずらし、余韻を重ねます。 | 0秒 / 0.12秒 / 0.24秒 |
| H2 | 同じド・ミ・ソを同時に鳴らします。 | 0秒 / 0秒 / 0秒 |

`index.html`で試聴・保存できる。WAVは48kHz・16bit・モノラル。頭に0.2秒、最後の音の2.62秒の余韻の後に0.35秒を確保。同じ70%音量とコンプレッサーを通し、ファイルごとの音量正規化や追加残響は行わない。

採用済みの `src/ui/voices.js` を読み、試作内だけで基音とアタック音の周波数を同比率で変更する。音源の別実装や、既存WAVの速度変更ではない。440Hzの比較信号が元の音源と完全一致することを検査。各音程・長さ・有限値・クリッピングなし・末尾の無音・音源の終了、PCブラウザのWAV読込と再生、ローカルファイルの試聴ページを確認。人の聴感、物理端末の音は未確認。詳細はverification.json。

再生成：`node 設計検証/build_bell_harmony_samples.cjs --playwright-path <playwright-coreのパス>`。試聴版と読込クエリは0.1.0。本体の版・音色・資材は変更しない。
