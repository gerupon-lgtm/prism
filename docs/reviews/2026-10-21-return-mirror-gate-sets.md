# 0.75.0：帰還・鏡・周期開閉の追加

## 採用条件と実装

発案者の指定順で各6面を追加し、全42面・実践288出題にする。25〜30面は星への帰還、31〜36面は鏡、37〜42面は周期開閉。各テーマに新背景を用意し、鏡にも透明背景の画像を追加した。[採用仕様](../proposals/2026-10-21-three-theme-expansion.md)・[画像の出所と生成指示](../assets/2026-10-21-theme-backgrounds.md)。

帰還の最初の指定回数で判定する方式は、発案者が明示承認した。間隔は完全一致で、判定対象の最後までに星へ戻って再分岐する必要がある。同時刻の処理を残したまま未来の光を終了する。これ以上鐘へ届かない配線も終了する。旧interval型の「ちょうど指定回数、追加到達なし」は変更しない。

鏡は1方向だけへ反射する。ドラッグと大きな方向ボタンで、前の出力を一度に置き換える。入力側の線は保持する。周期開閉は閉じている間に先着順で光を待たせ、開いた時に処理を始める。処理中に閉じても完了する。押下時に表示していた開始位置を固定し、開始演出の250msと音声の遅れは計算へ含めない。

## 計算・出題・保存の確認

- 各面8出題、追加144出題で、満点の配線1通り・別配線の部分点・満点配線が変わる2系統を確認。
- 帰還と鏡は許可された全配線を列挙。帰還は不正な間隔でも最初の指定回数まで進め、動作上限も計算する。
- 開閉は全許可配線と周期全体の0.1秒刻みを比較。数値変形は唯一の出発線を伸ばす対応関係を検査し、各変形でも満点と部分点を実行照合。満点の開始時間帯は連続1秒以上。
- 全追加144出題をSessionで実行し、満点・部分点・元条件と開始位置の保存・書出し・再挑戦・再抽選を照合。
- 旧24面の定義・旧144出題の内容を固定したハッシュで照合。旧144出題の全配線も再検査し、一意満点・部分点・分岐と待ちを保持。
- 周期境界の先着順、一時停止・再開、途中の負荷停止、鏡の双方向線、帰還の同時刻完了を独立した小さい回路で確認。

## 独立レビューでの修正

変更前の `a959edb` を基準に、仕様とコード品質を別々に読み取りレビューした。

- 幅0の縦線でも鏡の虹色を描けるよう、SVGのグラデーションを盤面座標で定義。
- 自由作成の鏡は、現在の線だけでなく他の全パーツを方向ボタンで選べる。未配線の相手も予告する。
- 読込みで同じ反射先へ有効な線が重複した場合は拒否し、鏡が分岐しないようにする。
- 既存の双方向線が入力側にある場合も、方向変更時にその線を再利用する。
