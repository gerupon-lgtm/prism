# リモートで確認すること

対象：本体0.109.0（スライドv0.1.4／曲v0.1.17）。パーカッションは3案比較から選択された「v0.1.15から+4dB」。[本番の確認入口](https://prism.sikumilab.com/?ending=1)から「曲を聴く」を押し、約3分7秒を通して確認する。通常の連続プレイと同じ画面を開くが、この入口ではクリア記録を作らない。古い版が表示された場合は、タイトルの更新ボタンで0.109.0へ更新する。

更新が時間切れになる場合は、未保存の回路を保存してからPRISMのタブとアプリを閉じ、このURLを開き直す。Chromeの旧版からの開き直しで、保存済みの成績と回路を保持して0.107.0へ移ることを検査した。

## 既にOKをいただいた内容

- 46〜47小節目は比較Aの旋律と、現行のC♯m→Eの伴奏。
- パーカッションは最大区間の+2／+4／+6比較から+4を採用し、全曲へ反映。
- 曲・スライドの全体構成はOK。今回の確認は、各場面に添えた本文とROOT NOTESの予告が中心。
- 弦の精霊の場面には、短い予告文と小さな「ROOT NOTES」の表記を添える方針。

## 実機で確認する点

- [ ] 縦置き・横置き・低い横置きで、絵・見出し・本文・ROOT NOTESの予告表記・ボタンが読めるか。
- [ ] 320px幅程度の小さい縦画面でも、お礼や引用表記の末尾が隠れないか。
- [ ] 選択したパーカッションの音量が全曲でちょうどよいか。音色はこれまでの好みを保っているか。
- [ ] 最後の鐘の余韻が途中で切れず、自然に曲後の画面へ進むか。
- [ ] 一時停止・再開・場面一覧・頭出し・消音・控えめ設定が使えるか。
- [ ] 別タブや別アプリへ移ると停止し、戻った際に勝手に鳴り始めないか。
- [ ] 約0.35秒の準備後、最初の鐘の出だしが途切れずに鳴るか。
- [ ] PWAで開いた直後、音ONのまま「曲を聴く」を押すと、ON/OFFを切り替え直さずに鳴るか。
- [ ] 曲中に画面が自動でロックされないか。一時停止・曲末・終了後は通常の自動消灯へ戻るか。電源ボタンや省電力モードの制限は別に扱う。
- [ ] ゲームの音・控えめ設定が引き継がれ、エンディングで変更した設定もゲームへ戻ると共有されるか。
- [ ] クレジットの「タイトルへ」でゲームへ戻れるか。ショートカットでの閲覧がクリア成績に加わらないか。
- [ ] 通信できる状態で準備が済んだ後、通信なしで開き直して曲を再生できるか。特にSafari実機は、Windows上の検査用WebKitの結果と分けて確認する。

PC上のブラウザ検査を実機の見え方・聴感の合格にはしない。発案者の追加指示により本体への組み込み・本番公開を先に行う。新しい文章と予告の表現は公開画面で確認する。ROOT本体の和解や「ええ。今度は、一緒に聴けますね」はPRISMで先取りしない。
