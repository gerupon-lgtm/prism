# 開閉の残り時間を小数点以下1桁へ（0.83.0）

盤面の開閉プリズムの残り時間を「開 · 1.0秒」「閉 · 1.0秒」のように小数点以下1桁で表示する。開始前のプレビューと実行中・一時停止中の表示、読み上げ用の説明に同じ書式を使う。計算値・開閉の時機・周期条件・採点・音・保存は変更しない。周期の説明に記載する元の条件値は精度を保持する。

表示版と読み込みの版を0.83.0へ更新した。構文98ファイルと既存の周期開閉テスト13件が合格。実配信用の`Board.updateGates`をChromium・WebKitで動かし、開始前と実行時計を用いる場合の開・閉、整数・小数の24項目が合格した。証拠は`設計検証/開閉時間表示/0.83.0/local/report.json`。実機の検査とは区別する。公開先の点検は後記する。
