## 追加到達があることを判断できる条件

条件を実行中に固定し、点と道の数、各点の分岐数、設定時間が有限で、道の移動時間は正、待ち列は先着順である。どの有限の実験時刻にも道の移動回数には有限の上界があり、有限分岐から発生する粒数・出来事数も有限である。0秒処理があっても、次の点へ移るには正の道時間が必要なので同時刻に無限個の新しい到着は発生しない。

ある粒が待ち列へ入る時、その前にいる粒は有限個。新しい粒は後ろに入るため、処理中の粒と前の粒の有限な処理が終われば、その粒も処理される。したがって対象の鐘まで許された有限の道筋が存在すれば、そこへ進む枝は有限の計算時間で到達する。負荷での一時停止は実端末の続行可能性であり、この計算上の道筋の有無とは分ける。

この前提の下で、移動中の移動先、処理中・待ち列の地点と直前の道を起点に、直前の道を除く転送と鐘での終了を反映した有限の状態グラフを調べる。対象鐘へ出られる道筋がなければ追加到達なし。あれば追加到達あり。調査の重複回避を実験の粒へ適用しない。開始前に達成通知せず、必要回数の実到達後に確認する。任意の再生時間で打ち切った観察を一般の証明にしない。

この成立の説明と代表・反例の自動確認を用意したが、画面・実機・負荷時の続行可能性まで確認済みではない。
