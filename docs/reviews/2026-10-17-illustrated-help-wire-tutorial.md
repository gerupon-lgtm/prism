# 図解付き説明と配線を消す練習

2026-10-17 / 0.51.0。実装・検証中。公開結果は確認後に追記する。

## 今回の指定

- パーツの説明に、名称が未確定の配線を追加する。今回は既存の「配線」を使い、全体の呼称変更はしない。
- 長押しで赤い線を確認し、「OK」で1本を消せることを説明する。取消・確認の外側では残し、全配線のクリアと区別する。
- 遊び方と概要を図で理解できる画面へ変える。
- チュートリアルにも削除とつなぎ直しの実操作を含める。

## 実装

採用済みの星・プリズム・鐘の画像と、盤面と同じ点線・金色・赤い線を使う。概要は「光をつなぐ」「鐘を鳴らす」「結果を比べる」「つなぎ直す」と、表示・モードの説明に分けた。スマホは図を上へ、PCは図と短い説明を横に置く。画面内で入る項目を表示し、前へ・次へと詳細の全文を用意する。文字を切り捨てたり、ページ全体をスクロールさせたりしない。

課題の練習は4段階：結線、確認付きの1本削除、つなぎ直して実行、記録を読む。自由の練習も4段階：実行を見る、停止して1本削除、つなぎ直しと時間変更、再実行。取り消しや別の線の削除では削除練習を済みにしない。全クリアでは案内の初めへ戻して行き詰まりを避ける。編集前の古い実行結果で後続の練習が進まないよう、編集後に実行し直した結果を使う。

対象の配線そのものを盤面で強調し、線を囲む四角い枠は出さない。削除確認中の赤い線は強調より優先する。案内は従来どおり盤面の外に置き、短い画面・文字拡大は全文の案内を読む入口を保持する。

短い画面では、案内を一瞬表示した状態の寸法でパーツの大きさを計算してから案内を隠していたため、結線後の大きさだけが変わった。案内の領域を確定してから盤面を描く順序へ直した。文字拡大で練習用の領域が極端に短い場合は、初期表示のパーツ画像を枠内に収める。点の位置、拡大・移動した表示、44px以上の操作判定は変えない。

既存の削除判定、停止、成績、保存、計算、音、演出設定、元の座標と向きは維持する。練習は別回路で行い、終了・スキップ・中断後は開始前の回路・実行記録・表示へ戻す。練習の点数を本番の成績に登録しない。
