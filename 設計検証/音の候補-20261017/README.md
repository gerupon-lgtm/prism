# ジングルとSEの試聴候補

試聴版：2026.10.17-1。本体は0.39.0のまま。採用済みの鐘は変更していない。

`index.html` を開くと、6種類それぞれの3案を個別に聴ける。ZIPは展開してから `index.html` を開く。ジングルは「鐘のあと／単独」を切り替えられる。別の音を再生すると前の音は停止する。

各 `*-comparison.wav` は、案1→2→3を続けて聴くための音源。ファンファーレ・通常クリア・未達成は毎回同じ採用済みの鐘を先に鳴らす。操作・結線・プリズム到着は、短音を聴き分けやすいよう各案を2回ずつ鳴らす。本体への採用後に2回鳴らすという意味ではない。

| 種類 | 案1（おすすめ） | 案2 | 案3 | 比較音源 |
|---|---|---|---|---|
| 100点 | F1 王道の祝福 | F2 星の祝祭 | F3 夜空の凱歌 | audio/perfect-comparison.wav |
| 通常クリア | C1 小さな達成 | C2 光のマレット | C3 やわらかな余韻 | audio/clear-comparison.wav |
| 未達成 | N1 もう一歩 | N2 鍵盤のため息 | N3 夜の小さな陰り | audio/failure-comparison.wav |
| 操作ボタン | T1 丸いタッチ | T2 澄んだタッチ | T3 軽いタッチ | audio/tap-comparison.wav |
| 結線 | W1 つながる2音 | W2 光る接点 | W3 軽いはめ込み | audio/wire-comparison.wav |
| プリズム到着 | R1 丸いピコン | R2 光片のきらめき | R3 鍵盤のピコン | audio/relay-comparison.wav |

おすすめは世界観と操作時の負担を考えた提案。聴感の採用は未確定で、種類ごとに違う番号を選んでもよい。

## 音と時間

既存曲を引用しない新しい短い譜面。録音した楽器ではなく、サエズリズムの楽器設定を使ってWeb Audioで合成した候補。

100点はブラス中心のファンファーレ。通常クリアは鍵盤・マレット・弦、未達成は柔らかい下降音・エレピ・弦で違いを付けた。ボタン・結線・到着のSEは、余韻を短くした。

共通音量は本体と同じ70%。鐘と組み合わせる場合、通常・満点は0.7秒後、未達成は1.5秒後に始める。新しい音はそれぞれ2.7秒／3秒の編集復帰より前に自然に終わる。鐘は本体の `bellVoice` をそのまま使って書き出した。
