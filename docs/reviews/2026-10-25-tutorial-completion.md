# チュートリアルのクリアと高得点の説明

2026-10-25、0.96.0。発案者の「終わりが分かりづらい」「クリア表示」「最速でのクリアが高得点」の依頼による。

## 変更

従来は最後の案内文と「完了」ボタンだけだった。課題のチュートリアルで最後の記録を確認し、閉じて再生後の編集状態へ戻った時に、「チュートリアルクリア！」の専用画面を一度表示する。自由作成のチュートリアルも最後の時間変更と再生を終えた後に表示する。記録を読んでいる間や別の説明・タイトル・非表示の間は開かない。

練習で実際に計算した到達時間を表示し、課題側は点数も示す。条件を満たしたうえで、短い時間でクリアするほど高得点となり、最速の配線で100点を目指すことを説明する。途中の記録を開く案内にも、早い到達ほど高得点で、この練習課題は最速なら100点になる説明を加える。「遊び方と概要」の結果説明にも追記し、本数も評価する課題があることを併記する。

「完了して戻る」で既存の完了履歴を保存して練習前の状態へ戻る。「練習を続ける」と×では履歴を付けず、練習を残す。閉じた画面が通常の更新で何度も自動表示されることはなく、「完了」から再度開ける。見出しも「チュートリアルクリア！」へ変え、完了後の「スキップ」は隠す。短い画面と文字拡大でも説明をスクロールでき、完了ボタンは画面に残す。

練習の達成条件や進行は変更しない。保存失敗時は完了を捏造せず、元の回路の控えと練習を残し、同じ画面から再試行できる。練習を通常の成績・保存回路へ混ぜない。自然終了後の自動表示は既存の音の余韻保持処理を使う。全42面288出題・採点・音色・保存と、通常の結果カード/再操作の同期・待機設定を保持する。表示/読込版を0.96.0へ更新する。
