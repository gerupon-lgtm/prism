# 鐘の音程試作 v0.2.0

2026-10-18。発案者の依頼により、採用済みの鐘からWAVを生成。アプリ本体へ未採用。

| ID | 内容 | 到達の間隔 |
|---|---|---|
| D2 | 前回のミ → ドを1オクターブ上へ。間隔は0.5秒のまま。 | 0秒 / 0.5秒 |
| H3 | C5 → G5 → C6。0.25秒ずつずらして余韻を重ねます。 | 0秒 / 0.25秒 / 0.5秒 |
| H4 | C5 → F5 → A5。0.25秒ずつずらして余韻を重ねます。 | 0秒 / 0.25秒 / 0.5秒 |

`index.html`で試聴・保存できる。WAVは48kHz・16bit・モノラル。頭に0.2秒、最後の音の2.62秒の余韻の後に0.35秒を確保。同じ70%音量とコンプレッサーを通し、ファイルごとの音量正規化や追加残響は行わない。

採用済みの `src/ui/voices.js` を読み、試作内だけで基音とアタック音の周波数を同比率で変更する。音源の別実装や、既存WAVの速度変更ではない。倍音を作る設定は変更せず、指定した音程と間隔の比較とする。440Hzの比較信号が元の音源と完全一致することを検査。各音程・長さ・有限値・クリッピングなし・末尾の無音・音源の終了、PCブラウザのWAV読込と再生、ローカルファイルの試聴ページを確認。人の聴感、物理端末の音は未確認。詳細はverification.json。

再生成：`node 設計検証/build_bell_harmony_samples.cjs --playwright-path <playwright-coreのパス> --revision 0.2.0`。試聴版と読込クエリは0.2.0。0.1.0の資料は元のフォルダへ保持し、新版は版ごとのサブフォルダへ出力する。本体の版・音色・資材は変更しない。
