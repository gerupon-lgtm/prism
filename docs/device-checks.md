# 実機確認の進め方

2026-10-13。確認用の公開版は0.9.0、[公開URL](https://gerupon-lgtm.github.io/prism/)。利用できる環境として、発案者からWindowsのChrome／Edge、AndroidのChrome、iPhoneのSafariが示された。Android/iPhoneのOS・ブラウザ版と実際の結果はまだ未確認。Windowsで取得した版と証拠は[Windowsの確認](reviews/2026-10-13-windows-browsers.md)を参照。Mac・iPadも要件の対象に残す。

PCの自動操作では、指・画面キーボード・OSの文字拡大・スピーカーの音・ホーム画面への追加を確認できない。まず短い一連の操作で実機の問題を見つけ、その後[受入条件26項目と非機能8項目](acceptance-status.md)の不足を確認する。以下だけの合格で全受入条件の完了とはしない。

2026-10-13の実機回答で0.9.0の配置不一致が指摘された。方向保持の修正は0.10.0候補でPC確認済み、公開後に版と手順を更新する。実機の合格は未確認。[修正の点検](reviews/2026-10-13-orientation-frame.md)を参照。

## 最初の一連の操作

1. 公開URLを開き、画面下の版が0.9.0であることを確認する。端末・OS・ブラウザ版を記録する。案内が出た場合は表示を確認し、進めるかスキップする。
2. 課題1でSからA、AからGへドラッグしてつなぐ。再生前に「音なし」をタップして「音あり」にしてから再生する。初回到着2.5秒・100.00点の表示、到着時の鐘の音、結線候補が分かることを確認する。消音で音が止まることも確認する。到着後に音を有効にした場合は停止して再実行する。音の余韻は記録の到着時刻へ加算しない。
3. 縦置きはSが下・Gが上であることを確認する。左へ90度倒すとSは右・Gは左、右へ倒すとSは左・Gは右となる。盤面と操作欄は端末に対して元の側を保ち、文字・ボタンの中身だけが読める方向へ回ることを確認する。点と道の配置を保ち、文字が読みやすい向きになること、ページをスクロールせず操作できること、回転前の実行・記録が残ることを確認する。盤面を長押しして不要なメニューが出ないことも確認する。
4. 自由へ移る。自由の案内が出たら完了またはスキップし、練習から元の回路へ戻ってから設定・保存を確認する。点・道をダブルタップして設定を開く。時間欄が全選択されること、画面キーボードが出ても入力・確定・取消ができることを確認する。OSやブラウザの文字を大きくした場合も、設定・保存・記録の全文をページ切替で読め、文書スクロールが起きないことを確認する。
5. 「実機確認」のような区別できる名前で手動保存し、回路ファイルを書き出す。保存先の既存枠を勝手に置換・削除しない。10枠とも使用中なら新規保存を中止し、ファイル出力まで確認する。別端末への受渡しと再実行は、ファイルを用意した後に行う。
6. 「オフラインと更新」で準備完了を確認し、端末のホーム画面へ追加する。機内モードなどでWi-Fi・携帯通信を切り、アプリを終了して起動する。課題・自由・保存読込が使えること、回路・成績・案内履歴が保たれることを確認する。単に開いたまま接続を切る確認とは分ける。

## 記録のしかた

各環境ごとに、端末／OS／ブラウザ版、確認した公開版、各手順の合格・不合格・未確認、問題が出た操作を記録する。聞こえた音は実発音の観測、負荷は実際に使った回路と遅れを記録する。PCの合成遅延や音のAPI呼出しを実機結果として転記しない。実行結果や回路ファイルに含まれる利用者の記録を無断で公開しない。

この一連の後も、全故障ケース・循環と待ち列・記録の親子・保存失敗時の退避・明示更新と復旧・OS終了後の保持・実負荷・異なる端末への受渡しなどはAC別に照合する。手順の回路・粒数・時間は試験例であり、製品の上限ではない。
