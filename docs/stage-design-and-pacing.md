# 面ごとの考えどころと緩急

2026-10-23改訂。これは作問の設計意図で、実機で確認済みの難易度表ではない。機械検査は成立・満点の一意性・部分点・再生時間・必須の分岐や待ちを確認する。楽しさや、考えるのに何分かかるかは実プレイで評価する。

数字の差や未採用線の本数を、推論の深さの証拠には使わない。代表出題では満点と、もっともらしい別の配線の再生を比べ、どこが違ったかを結果と盤面から追えることを確認する。全体の配置と線の数を増やして難しくしない。
