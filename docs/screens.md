# プリズム・ノーツ 画面と主要状態

ドラフト v0.1 / 2026-10-12。画面IDは設計上の機能領域を示し、独立したページ数ではない。配置の細部は実装時に調整する。

## 1. 画面構成

0.17.0では配線が0本の時だけ「流す」を無効にし、「点をつないでから流してください」と理由を表示する。1本以上なら到達不能でも試行を受け付ける。全配線クリア・最後の道の削除後は開始できず、結線や復元で開始可能へ戻る。直前の停止後記録・結果は消さない。鐘は5度上、中継音も同じ幅で高くし、回数・余韻・計算時間の扱いは維持する。

0.16.0の後続指定で、移動中の音を削除し、中継点に入った時に短い「ピコン」を1回鳴らす。待ち列に入った粒も処理開始を待たず到着時に鳴らす。出発点・ゴールでは中継音を鳴らさず、鐘の余韻中は通知を省略する。消音・一時停止・停止で止め、計算・記録時間へ加えない。[中継到着音の点検](reviews/2026-10-13-prism-arrival-audio.md)を参照。以下の周期音は履歴。

後続の「では3秒で」で、ゴール到着がある実行は全粒終了から3秒で自動的に編集へ戻すことを採用。「停止」なら即時。実験の時計・全記録・点数・配線・保存を維持し、負荷やエラーによる中断を自動停止しない。[編集復帰の点検](reviews/2026-10-13-ending-return.md)を参照。以下の明示停止だけという記述は0.14.0以前の履歴。

2026-10-13の後続指定で移動音は一定音から短音へ変更する。0.1秒間隔・330Hzを初期値とし、ソース先頭の定数で間隔を変更できる。全粒の待機・停止と鐘の余韻中には鳴らさない。到着後に操作禁止の待ち時間は設けず、配線の再編集は明示的な停止で戻る。[短音化の点検](reviews/2026-10-13-movement-pulses.md)を参照。

プレイ中の結線を優先するため、設定は普段閉じ、必要な場面で重ねる。通常の記録閲覧では盤面を残し、スマホの手入力中だけ専用表示を使う。

2026-10-13の追加要求で、全配線だけを消す「クリア」、候補を順に通る連続ドラッグ、ON/OFF付きの拡大補助を追加する。点・設定・保存枠・停止後の記録をクリアの対象にしない。接続外で離した場合はそのドラッグ全体を取消す。通常の個別ドラッグとダブルタップ設定を維持する。拡大補助の余白・密集時の表示条件と現在の証拠は[点検記録](reviews/2026-10-13-wiring-help.md)を参照。

同日の追加要求で、ボタンの持続状態を背景色、押下を短い反応で示す。メニューは項目を減らさず1ページの複数列とし、狭い画面は短縮名と全文の読み上げ名を併用する。準備できた更新を版表示付近の小さいボタンで知らせ、利用者が選んだ後に既存の保護確認へ進む。音あり時の操作音と移動音、鐘との分離、現在の証拠は[点検記録](reviews/2026-10-13-controls-audio-update.md)を参照。

盤面は余白ドラッグで表示移動し、ホイール・二本指・＋−・全体表示で拡大縮小する。盤面の移動とページ全体のスクロールを区別する。SD-058の端末基準の位置保持を採用する。2026-10-13、発案者が「縦置きでスタートが下、ゴールは上。横置きにしたときは、配置は変わらず文字やボタンだけ読める方向に回転」と再確認した。盤面だけでなく、追加・拡縮・再生などの操作欄も元の側に保つ。0.9.0の実装はこれと不一致だったため0.10.0で修正し、PCの方向保持28項目とWindows Chrome/Edgeの各14項目を確認した。実機の方向通知・指操作・切り欠きは未確認。旧画面案と過去の表示合格を新方式の合格と扱わない。

本文の書体は `"Noto Sans JP", "Hiragino Sans", "Yu Gothic", "Meiryo", sans-serif` を暫定指定【想定】。採用ロゴのMontserratは維持する。必要な資材をオフライン用に用意し、配色・アイコン・寸法をここで追加確定しない。

## 2. 主要状態と戻り先

| 領域・状態 | 入口／正常な次 | 戻る・中断 | 空状態・失敗時 |
|---|---|---|---|
| プレイ・停止中 | 課題選択／自由の見本・保存回路。編集後「流す」で条件固定 | 未保存の案を読込で置換する際はS-05の保護。接続外で指を離したら新しい線だけ取消 | 配線0本は開始拒否。1本以上の途中結線・到達不能は有効な実験結果として扱う。入力不正は理由を表示し保持 |
| プレイ・実行中 | 粒・時計・待ち列・結果を更新 | 一時停止、記録表示、停止。回転では条件・状態保持。負荷停止も状態保持 | 未確定の判定を未達成0点にしない。達成通知だけで動作を止めない |
| プレイ・一時停止 | 明示再開、次動作で同時刻のまとまりを処理し再停止 | 停止して編集へ。条件は一時停止中も変更しない | 表示・音の余韻と時計を分離。状態を失わず理由を表示 |

| 記録・ケース | 記録を開く操作で一時停止。前後ページ・詳細を表示 | 閉じてプレイへ、自動再開なし。設定切替後もページ位置保持 | 記録0件も戻れる。全件を辿り、表示都合で記録を捨てない |

## 3. 操作の確認範囲

全対象端末の縦横、キーボード表示、回転中断、文字拡大で一画面の収まりを確認する。ドラッグ・ダブルタップ・全選択・貼り付け・盤面の拡大縮小を両立させ、不要な長押しメニューを抑える。入力欄の必要な操作を妨げない。読める表示と操作範囲の具体値は実機で調整し、成立困難なら説明する。

画面案のPCブラウザ214件は回転変更前の配置・見本操作の証拠。実際の結線・計算・保存・音・PWA・スマホ実機の合格とは別。新しい試作は本ドラフトの作成条件にしない。
